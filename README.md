# Quiz
Dieses Repository beinhaltet die öffentlich Fortsetzung eines privaten Entwicklungsprojekts für eine Quiz. <br>
Unterstützt wird aktuell Multiple Choice mit beliebig vielen Antwortoptionen in Textform.<br>
Die Frage kann durch ein Bild ergänzt werden. Weitere Quizkartentypen sind bereits in Planung.<br>
Für jede richtige Antwort werden Punkte gesammelt. Ein Leaderboard ist geplant, aktuell aber noch nicht implementiert.<br>

Das Quiz ist durch einen Login geschützt, Accounts können nur über die Administrationsfläche angelegt werden. Eine eigenständige Registrierung ist nicht möglich.
